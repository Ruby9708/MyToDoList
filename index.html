Firebase 專案設定

💡 如何取得 API 金鑰與設定：

1. 前往 Firebase Console 進入專案 my-to-do-list-1d256

2. 點擊「專案設定 (Project Settings)」 > 「一般 (General)」

3. 捲動至「您的應用程式」，選取或新增「網路應用程式 (</>)」並複製 firebaseConfig
